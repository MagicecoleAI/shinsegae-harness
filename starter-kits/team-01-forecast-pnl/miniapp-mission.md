# 예상손익 샘플 미니앱 Mission

## 목표

더미 CSV에서 법인·프로젝트별 계획손익·실제손익·차이와 확인 필요 항목을 보여주는 교육용 미니앱을 만듭니다.

## 최소 화면

- 계획손익·실제손익·차이 요약 카드
- 법인·프로젝트별 결과표
- 누락·합계 이상·확인 필요 목록
- `검토 전·승인·수정 필요` 상태

## 변경미션

사용자가 차이 기준을 입력하면 기준을 넘은 항목을 강조하고 `차이 큰 항목만 보기` 필터를 추가합니다. 계획이 0이면 차이율을 임의 계산하지 않습니다.

## 하지 않을 것

- 실제 손익자료·SAP 연결·자동 승인
- DCF·투자판단·복잡한 Dashboard
- 외부 API·패키지·DB

## 완료증거

- 더미 CSV 기반 요약·결과표
- 차이 기준 변경 전후 화면
- 계획 0·빈 값·숫자 오류 처리
- 사람 검토상태
- 실패 한 건과 수정·재실행 결과

상세 Prompt와 Fallback은 공개 사이트의 `1조 · 예상손익` 페이지와 `Claude Code 미니앱 제작 Playbook`을 사용합니다.
