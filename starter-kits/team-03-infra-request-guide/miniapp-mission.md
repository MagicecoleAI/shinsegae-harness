# 인프라 요청 가이드 샘플 미니앱 Mission

## 목표

가상 요청에 대해 승인된 더미 가이드의 근거·누락질문·JSM 요청서 초안과 사람 승인상태를 보여주는 미니앱을 만듭니다.

## 최소 화면

- 가상 요청내용·서비스 유형
- 근거문서·절·기준일
- 추가로 필요한 질문
- 안내·JSM 초안·검토상태

## 변경미션

필수정보가 빠진 요청은 확정을 막고 누락항목·필요이유·담당자 문의문을 표시합니다. 근거 충돌은 `담당자 결정 필요`로 남깁니다.

## 하지 않을 것

- 실제 JSM 등록·Terraform·인프라 변경
- 내부 정책 공개·보안 승인·외부지식 추측

## 완료증거

- 대표 요청·근거 안내·요청서 초안
- 누락정보 차단 전후
- 근거 없음·정책 충돌 처리
- 실제 시스템 실행이 없는 상태
- 실패·수정·재실행 결과

상세 Prompt와 Fallback은 공개 사이트의 `3조 · 인프라 요청` 페이지와 공통 Playbook을 사용합니다.
