# Demo AWS Migration Guide

- 기준일: 2026-07-01
- 상태: 교육용 승인 Sample

## A. 요청 전 필수 정보

서비스 목적, 현재 3-Tier 구성, 월평균·최대 트래픽, 데이터 등급, 목표 가용성, 이전 희망일, 운영 담당 역할을 준비한다.

## B. 기본 매핑 예시

Web·Application·Database 계층을 분리해 설명하고, 각 계층의 용량·네트워크·백업 요구를 요청서에 적는다. 특정 AWS 서비스 선택은 담당 Architect 검토 후 확정한다.

## C. 금지

가이드만으로 계정 생성, 보안그룹 변경, 운영 배포를 승인하지 않는다.
