# Infra Request Guide Project Rules

## Goal

승인된 더미 가이드에서만 근거를 찾아 안내와 JSM 요청서 초안을 만들고, 근거 부족과 사람 승인 항목을 분명하게 표시한다.

## Rules

- `samples/input/guides/` 밖의 문서를 내부 정책처럼 사용하지 않는다.
- 모든 답변에 문서명, 절, 기준일을 붙인다.
- 근거가 없거나 충돌하면 추측하지 않고 중단·확인 요청한다.
- 필수 사양이 빠지면 질문을 만들고 요청서를 `작성 중`으로 둔다.
- 실제 JSM 등록, Terraform 실행, 계정·서버·네트워크 변경을 하지 않는다.
- 내부 정책 원문, 운영 구성, 접근키를 요청하거나 저장하지 않는다.
- 결과는 `outputs/`에만 저장한다.

## Done

근거 안내, 요청서 초안, Reviewer 의견, 사람 승인 목록, Test Log가 있어야 완료다.
