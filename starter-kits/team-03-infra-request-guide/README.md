# Team 03 · Infra Request Guide Starter

승인된 더미 IDC·AWS 가이드에서 근거를 찾아 안내와 JSM 요청서 초안을 만드는 시작 폴더입니다.

## 5단계 시작

1. `CLAUDE.md`와 `.claude/agents/`를 읽습니다.
2. `samples/input/guides/`와 `request.md`를 확인합니다.
3. `/infra-request-guide` 또는 자연어로 근거 찾기 계획을 요청합니다.
4. `outputs/guidance.md`와 `outputs/jsm-request-draft.md`를 만듭니다.
5. 근거 없음·정책 충돌·금지 요청을 포함한 Test 10개를 실행합니다.

실제 JSM 등록, 운영 명령, 인프라 변경, 보안 승인은 하지 않습니다.
