# Team 02 · Weekly Report Starter

저장된 더미 팀 보고를 모아 전주 변화·근거·확인 필요가 있는 한 페이지 초안을 만드는 시작 폴더입니다.

## 5단계 시작

1. `CLAUDE.md`와 역할 파일을 읽습니다.
2. `samples/input/`의 현재 주 3개와 이전 주 1개를 확인합니다.
3. `/weekly-report` 또는 자연어로 수집 계획을 요청합니다.
4. 결과는 `outputs/weekly-report-draft.md`에 저장합니다.
5. 10개 Test와 팀장 확인 목록을 기록합니다.

메일·메신저 연결, 자동 발송, 실제 인사·성과정보는 범위 밖입니다.
