# 주간보고서 샘플 미니앱 Mission

## 목표

더미 팀 보고를 통합해 전주 변화·근거·누락·상충·확인 필요가 있는 한 페이지 보고 미리보기를 만듭니다.

## 최소 화면

- 입력문서 목록과 기준주차
- 주요 성과·전주 변화
- 이슈·다음 계획
- 원문 위치·누락·상충·팀장 검토상태

## 변경미션

`확인 필요 항목만 보기` 기능을 추가하고 누락·상충 항목을 선택하면 원문 파일명과 항목을 보여줍니다.

## 하지 않을 것

- 실제 메일·메신저 수집·자동발송
- 실제 인사·성과정보
- 근거 없는 성과평가·외부 API·DB

## 완료증거

- 팀 보고 2개 이상과 한 페이지 결과
- 전주 변화·원문 위치
- 확인 필요 필터 전후
- 상충 수치 처리
- 실패·수정·재실행 결과

상세 Prompt와 Fallback은 공개 사이트의 `2조 · 주간보고서` 페이지와 공통 Playbook을 사용합니다.
