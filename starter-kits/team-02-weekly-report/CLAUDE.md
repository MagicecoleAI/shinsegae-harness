# Weekly Report Project Rules

## Goal

더미 팀 보고 3개를 한 페이지 주간보고 초안으로 통합하고 출처·전주 변화·누락·상충·팀장 확인을 표시한다.

## Rules

- `samples/input/` 원본을 수정하지 않는다.
- 없는 성과, 수치, 완료 상태를 만들지 않는다.
- 모든 핵심 항목에 원문 파일과 항목을 남긴다.
- 상충하는 수치는 하나를 선택하지 말고 모두 표시한다.
- 개인정보와 민감 문구는 결과에서 제외하고 사람 확인으로 보낸다.
- 메일·메신저를 읽거나 발송하지 않는다.
- 결과는 `outputs/`에 저장한다.

## Done

한 페이지 초안, Reviewer 의견, Test Log, 팀장 확인 목록이 있어야 완료다.
