# MARK Monitor Project Rules

## Goal

저장된 공개 Snapshot 3종에서 중복을 줄이고 출처·게시시각·수집시각·중요도 근거가 있는 Markdown Brief를 만든다.

## Rules

- Source URL과 시각이 없는 항목은 핵심 Brief에서 제외한다.
- 게시시각과 수집시각을 구분한다.
- 상충 정보는 한쪽을 선택하지 않고 모두 표시한다.
- 중요도는 `monitoring-rules.md`의 명시 규칙만 사용한다.
- AI 요약과 원문 사실을 구분한다.
- 투자·매매 추천, 인과 단정, 자동 발송을 하지 않는다.
- 로그인 우회, 접근 제한 회피, 이용약관 위반 수집을 하지 않는다.
- 결과는 `outputs/`에 저장한다.

## Done

Brief, Reviewer 의견, Source 목록, Test Log, 사람 승인 목록이 있어야 완료다.
