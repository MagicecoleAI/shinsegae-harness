# WBS Daily 샘플 미니앱 Mission

## 목표

더미 WBS에서 지연·담당 누락·상태 불일치·다음 마감·판정이유·사람 확인을 보여주는 미니앱을 만듭니다.

## 최소 화면

- 전체·완료·지연·담당 누락 요약
- 지연·상태 불일치 목록
- 다음 7일 마감
- 원본 행·판정이유·PM 검토상태

## 변경미션

`다음 7일 마감만 보기` 기능과 판정이유를 추가합니다. 원본 수정 요청은 실제 반영하지 않고 별도 `수정 제안`에만 표시합니다.

## 하지 않을 것

- 원본 WBS 자동수정·자동독촉
- 실제 실명·성과평가·완료일 예측

## 완료증거

- 지연·담당누락·다음 마감 화면
- 7일 마감 필터 전후
- 판정이유·원본 행
- 날짜·상태 오류 처리
- 원본 미수정·사람 검토상태

상세 Prompt와 Fallback은 공개 사이트의 `5조 · WBS` 페이지와 공통 Playbook을 사용합니다.
