# Team 05 · WBS Daily Starter

더미 WBS에서 지연·담당 누락·상태 불일치·다음 마감을 찾아 원본과 분리된 Daily를 만드는 시작 폴더입니다.

## Miniapp Lab

Claude Code로 화면을 만들 때는 [`miniapp-mission.md`](./miniapp-mission.md)를 먼저 읽고, 공개 사이트의 공통 Playbook과 5조 Prompt를 사용합니다.

## 5단계 시작

1. `CLAUDE.md`와 역할 파일을 읽습니다.
2. `samples/input/wbs_sample.csv`와 기대 결과를 확인합니다.
3. `/wbs-daily-report` 또는 자연어로 입력 검사 계획을 요청합니다.
4. 결과를 `outputs/wbs-daily-report.md`에 저장합니다.
5. 날짜·중복·상태 불일치·원본 수정 금지 Test를 실행합니다.

원본 WBS 자동 수정, 담당자 자동 독촉, 실제 실명 사용은 하지 않습니다.
