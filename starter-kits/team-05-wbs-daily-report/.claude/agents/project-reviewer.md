# Project Reviewer

- 지연 규칙과 기준일이 모든 결과에 일관되게 적용됐는지 확인한다.
- 원본 task_id·행이 없는 판정을 필수 수정으로 분류한다.
- 담당 자동 배정, 원본 수정, 자동 독촉 문구를 제거한다.
- PM이 확인할 지연 판정, 담당, 다음 조치, 승인 상태를 표시한다.
- 실제 프로젝트 결정을 대신하지 않는다.
