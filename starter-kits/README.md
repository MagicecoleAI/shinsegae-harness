# Shinsegae Harness Starter Kits

각 폴더는 공개·더미 데이터만으로 팀별 핵심 흐름을 시작할 수 있는 Claude Code 하네스입니다.

1. 팀 폴더를 복사합니다.
2. Claude Code에서 복사한 폴더를 엽니다.
3. `README.md`, `CLAUDE.md`, `miniapp-mission.md`, `samples/`, `tests/`를 먼저 읽게 합니다.
4. 공개 사이트의 [Claude Code 미니앱 제작 Playbook](https://magicecoleai.github.io/shinsegae-harness/02-common-lab/)에서 읽기·계획·구현·오류수정 Prompt를 복사합니다.
5. Claude의 계획을 팀이 줄인 뒤 첫 실행화면을 만듭니다.
6. `miniapp-mission.md`의 작은 변경기능 한 가지를 구현합니다.
7. 실제 화면·결과파일·실패·사람 확인을 기록합니다.

이 Starter는 완성 애플리케이션이 아닙니다. Claude Code로 직접 미니앱을 만들고 시행착오를 경험하도록 업무규칙·더미 Sample·원하는 결과·시험만 제공합니다. 실제 팀 Agent 주제는 샘플 경험 후 별도로 확정합니다.
