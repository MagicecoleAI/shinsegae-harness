# Shinsegae Harness Starter Kits

각 폴더는 공개·더미 데이터만으로 팀별 핵심 흐름을 시작할 수 있는 Claude Code 하네스입니다.

1. 팀 폴더를 복사합니다.
2. Claude Code에서 복사한 폴더를 엽니다.
3. `README.md`, `CLAUDE.md`, `samples/`, `tests/`를 먼저 읽게 합니다.
4. KEEP·REPLACE·DELETE를 확정합니다.
5. Bronze 결과파일부터 구현합니다.

이 Starter는 완성 애플리케이션이 아닙니다. 2주차 v2.0과 팀의 공개·더미 Sample에 맞게 수정한 뒤 테스트해야 합니다.
