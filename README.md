# Shinsegae Harness

신세계 I&C AI4PM 5개 팀이 Claude Code로 하루 안에 업무 하네스의 핵심 흐름을 구현하고 검증할 수 있도록 만든 공개 실습 사이트입니다.

초보자도 따라갈 수 있도록 공통 `Claude Code 미니앱 제작 Playbook`과 예상손익·주간보고·인프라 요청·MARK·WBS 5개 팀별 실행 Prompt·변경미션·Fallback을 제공합니다.

- Site: <https://magicecoleai.github.io/shinsegae-harness/>
- Starter kits: `starter-kits/`
- Local build: `bundle exec jekyll serve`

## Public-content policy

이 저장소에는 공개·더미·비식별 데이터만 포함합니다. 참가자 사진, 이름, 발표 원본 PDF, 실제 재무 수치, 운영 로그, 접근키, 내부 정책 원문은 포함하지 않습니다.
